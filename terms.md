## Terms & Conditions

By taking part in the APSIPA RADAR Challenge, participants agree to the following terms:

### 1. Challenge data

The organizers will provide a development set and an evaluation set. The development set is for system development and tuning. The evaluation set will contain speech processed with unknown media transformations, and ground-truth labels will not be released to participants.

### 2. Training data policy

No official training set will be provided by the organizers. Participants have to use publicly available datasets only, provided that they follow the relevant dataset licenses and terms. All training data used must be open and accessible to all participants. The use of LlamaPartialSpoof and LibriTTS dev/test sets, as well as their derivatives (including original LibriSpeech), is strictly forbidden. All training datasets used must be disclosed in the final system description.

### 3. Use of evaluation data

Evaluation data must be used for testing only. Participants must score each evaluation utterance independently. Any use of evaluation data for model training, adaptation, calibration, or score normalization is strictly prohibited.

### 4. System description

Each team must provide a system description for its final submission. This description must clearly state the training data used, model configurations, and any important processing steps used.

### 5. Evaluation and ranking

The primary evaluation metric is Equal Error Rate (EER). Final rankings will be based on EER on the evaluation set. Other metrics may be later reported for analysis, but they will not be used for the official ranking.

### 6. Compliance and fair participation

Participants are responsible for making sure that their submission follows the challenge rules and data policy. The organizers reserve the right to reject, exclude, or remove any submission that does not follow these terms.

### 7. Timeline and updates

Participants are expected to follow the official challenge timeline for data release, submission, and paper deadlines. As stated in the proposal, the timeline is tentative, and the organizers may update it if needed.
